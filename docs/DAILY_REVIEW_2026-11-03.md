## WORK-11 읽기 대조 — Soccer 범위

운영 커밋 `b3b96fd29f778ef5b44084cb96e2130c93a8a30c`의 `src`·`package.json`에서 주요 분석 SDK/저장 이벤트 호출을 검색하고 [기존 원천 인계](METRICS_SOURCE_INVENTORY.md)를 대조했다. 해당 검색에서 분석 SDK·저장 시도/실패 이벤트 호출을 찾지 못했다. 이것이 호스팅 자동 이벤트가 없다는 뜻은 아니며 콘솔 자동 수집 설정은 확인하지 않았다.

Soccer의 `match_date`는 경기 DATE이고 기록 `created_at/updated_at`과 다르다. WeTheOne 체크인 날짜를 대신하는 지표로 쓰지 않는다. 현재 원천 문서상 일관된 `is_demo/is_test` 표시가 없으며 실제 제외 대상은 미확인이다. 이번 브라우저는 인증·저장을 가상 데이터로 가로채므로 실사용 cohort에 포함하지 않는다. 실제 사용자·활성·반복 수치를 새로 집계하지 않았고 DB 접근 거절을 재시도하지 않았다. WeTheOne 배포 이벤트·체크인 대조는 해당 제품 담당의 별도 범위다.
