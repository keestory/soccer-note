## 비용 근거와 한계

지원되는 현재 Vercel 읽기에서 Soccer Note 프로젝트가 속한 팀은 Hobby로 확인됐다. 공식 [가격 FAQ](https://vercel.com/pricing)는 Hobby가 사용량 제한을 적용하며 추가 사용량을 구매할 수 없다고 설명한다. [Hobby 정책](https://vercel.com/docs/plans/hobby)은 한도 초과 시 대기를 안내하고, Pro 전환을 사용자의 명시적인 업그레이드 절차로 설명한다. [Functions 요금표](https://vercel.com/docs/functions/usage-and-pricing)에도 Hobby의 초과 사용량 요금은 없으며, [배포 제한](https://vercel.com/docs/limits)은 하루 100회다.

따라서 **현재 Hobby를 유지하고 유료 기능을 추가하지 않는 일반 배포·호스팅·Functions 사용에서는 한도 초과를 자동 유료 전환이나 초과 청구로 볼 근거가 없다.** 월간 잔량 불명은 우선 실행 차단·중단 가능성이라는 가용성 문제다. Hobby에 적용되지 않는 Spend Management 설정을 추가 조건으로 요구하지 않는다.

월간 잔량은 여전히 미확인이다. 지원된 billing charges 조회는 `404 costs_not_found`를 반환했으며 재시도하지 않았다. 이것은 사용료 0원이나 잔량 충분의 증거가 아니다. 현재 팀 플랜과 공개 정책 근거를 실제 계정 전체 청구서·모든 외부 서비스 무료 보장으로 확대하지 않는다. 이번 재현은 호스팅 배포나 운영 DB 요청 없이 진행했다. 네이티브 에이전트 모델 청구·모델 정체성·저장소 CLI 실행 성공 여부와도 별개다. 이전 CLI/권한 차단은 변경하지 않았다.
