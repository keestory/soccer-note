# GOLDLINE / Volt restoration — 2026-10-31

## Scope

Restore the original near-black / volt neon visual language from `fedd654` and `f9f4f10`, preserving the current Home / Matches / Team navigation, state-aware Home, player entry, accessible sheets and formation controls. No database, permission, native SDK or persistence contract changes. A valid saved personal accent is retained; the retired forest default migrates to volt.

The root owns theme tokens, including dark warning/loss surfaces. Legacy light wrappers inherit those tokens. Fixed light backgrounds/text in roster, player statistics, team management, training, community and status cards now use dark semantic colors. Scores use the existing Bebas Neue font. Metadata uses readable gray instead of the old low-contrast olive.

- UI/UX: historical palette and typography verified; default/upcoming/long-name Home screenshots passed. The two-digit score remains visible and upcoming-match priority is preserved.
- QA: actual roster and player-statistics routes checked with fictional local auth/data at 320, 390 and 430 CSS pixels. No document overflow, white main card remnants or runtime exceptions. Chart and status-card contrast defects were fixed and rechecked.
- Source review: changed TSX files contain no business, authorization or save-flow changes beyond theme handling; structural comparison performed independently.

## Build dependency repair

The official [October 14 security update](https://nextjs.org/blog/nextjs-security-update-october-14-2026) identifies fixes beginning in 16.4.1. Next.js and eslint-config-next are pinned to 16.4.3, with only their matching @next packages changing in the lockfile. React / React DOM stay at 18.3.1 and the package count is unchanged.
